# Capturas de ejecución

Ejecutar primero Apache, MySQL y `ionic serve`. Después guardar en esta carpeta:

1. `01-login.png`: formulario de inicio de sesión.
2. `02-sesion.png`: Tab 1 con la cuenta autenticada.
3. `03-usuarios.png`: Tab 2 mostrando al administrador y al menos un usuario normal.
4. `04-oraculo.png`: Tab 3 con la pantalla principal del Oráculo MLB.

Para mostrar dos registros en la captura de usuarios, entrar como administrador y utilizar **Nuevo usuario** antes de tomarla.

Las capturas deben mostrar únicamente datos de desarrollo; no se deben exponer contraseñas ni tokens.
