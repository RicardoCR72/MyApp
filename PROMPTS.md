# Prompts relevantes utilizados

## Login y rutas

> Migra la vista Tab1Page hacia una página de login para una aplicación Ionic Angular con NgModules y agrega la ruta correspondiente.

## API de autenticación

> Crea una API PHP conectada a MySQL que permita iniciar sesión desde Ionic utilizando Axios.

## CRUD de usuarios

> Crea un endpoint PHP con CORS que implemente GET, POST, PUT, PATCH, DELETE y OPTIONS para administrar usuarios.

## Modelo de datos

> Genera el modelo SQL necesario para usuarios y tokens de autenticación, incluyendo una carga inicial con un administrador y un usuario normal.

## Persistencia local

> Agrega Capacitor Preferences para conservar el token, el usuario autenticado y la fecha de expiración después de cerrar y reabrir la aplicación. Restaura la sesión antes de evaluar las rutas protegidas y elimina los valores al cerrar sesión.

## Verificación

> Revisa que la implementación de persistencia compile, pase el linter y mantenga funcionando el CRUD de usuarios mediante Axios y PHP.
